## What does DLTNG Upgrade do?

DLTNG Upgrade guides you through reinstalling a CM4 DLTNG. Settings, data files and databases are backed up before the device is overwritten. The wizard then restores the data into the new system and checks the result.

<div class="grid cards" markdown>

- **Back up first**

    A mandatory data backup, with an optional complete copy of the existing device storage.

- **Clear steps**

    Ten steps, clear status messages and symbolic illustrations guide you through the process.

- **German and English**

    The country flag at the top right changes the language immediately. Your session and inputs are preserved.

- **Portable on Windows**

    One executable, no Python installation. Backups stay in your chosen work folder.

</div>

## Which devices?

The intended devices are CM4 models with 16 or 32 GB eMMC running DLTNG 9.5 or 10.x. UPS determines the matching approved target version. Flashing uses the USB programming connector; backup and restoration use Ethernet.

!!! info "Current status: development edition @@VERSION@@"

    The download is public. This edition is intended for trying the complete demo and prepared lab tests. Customer flashing remains disabled until hardware approval is documented. Real migrations, interruption tests and exact connector illustrations still require validation.

The clean test image has been built and checked in software. This does not confirm a successful upgrade of a physical device. [Read the image changelog](image-changelog.md).

## Try it quickly

1. [Download the portable executable](download.md).
2. Start `DLTNG-Upgrade.exe`.
3. Choose **Deutsch** or **English** at the top right.
4. Select **“Try the demo”** and follow every step.

The demo does not change any device. You do not need a ChatGPT account to use the tool.
